# Formula tooltips, symbol keys and central constants

Scope of this pass: General Chemistry I (course 84101), theory tab only.

## What the reader sees
Every formula in the GC1 theory is its own block. Hover, keyboard focus or a tap opens a popup that repeats the formula and lists each symbol with its meaning. On narrow screens the popup is a bottom sheet with its own scrolling and a close button; on wide screens it opens on the side with more room and scrolls inside. Escape, the close button or a tap outside closes it. Printing hides the popup and prints the same symbol key under the formula.

The only formula without a key is the permanganate redox equation in G8, which contains only chemical formulas.

## Where things live
- `src/constants.js`: the value of R, Nₐ and k, their units, and how many digits to display. Variants of R: SI (`R`), L·atm (`R@latm`, 4 digits), `R@latm5` (5 digits) and `R@sheet` (2 digits, the value on the exam sheet). Change a digit count here and every key, popup, print key, equation block and glossary entry that uses `{R}`, `{R@latm}` and so on changes with it. Stored values are never rounded.
- `src/symbol-defs.js`: the meaning of each symbol, as runs of Hebrew text, `{math}` (always left to right) and `{const}` (read from constants.js). Generated by the notation pass; edit meanings here.
- `src/symbols.js`: row and text helpers.
- `src/notation-corrections.json`: for every paragraph that was reformatted, the original block, so tests can rebuild the original text.

Meanings are context-specific. Ēₖ per mole (J/mol) and per molecule (J) are separate rows. R has one key per context: SI for energy formulas, L·atm where the formula uses it, and one key that states both values together with the pressure and volume units that select each. M means molar mass in most places and molarity in solution chemistry. R means activity in the radioactivity topic.

## Regression tests
`tests/notation.test.js` protects semantics: every original formula run survives in the new blocks, no equation block contains Hebrew, symbol ids resolve and are used, constants format correctly and follow a digit change, the popup markup, the print key and the radical-sign bidi case from the original bug report. The baseline tests rebuild original text with `tests/notation-baseline.js`; they do not re-bless hashes.

## Known limits
Numbers in prose, worked solutions, quizzes, exam problems, figures and the formula sheet are still literal text and are not driven by constants.js. See the migration scope in the pull request description.
