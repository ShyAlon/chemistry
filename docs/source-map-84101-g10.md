supplied pages. Convention: PDF page = page of the file as sent (in this deck
the printed slide numbers match the PDF pages; page 1 is the title). "Checked"
means compared against the lesson content on the date noted. Coverage labels:

- **covered** — the same content is presented directly on the site.

  computed figure) but the source's own artwork or framing is not reproduced.
- **gap** — missing; needs a correction.
