# SPECTRA - המעבדה האישית לכימיה

אתר לימוד אישי בעברית, React + Vite, ללא שרת וללא חשבון.

## הפעלה במק

1. חלצו את קובץ ה-ZIP.
2. נדרשת התקנת Node.js בגרסת 20.19 ומעלה (או גרסת LTS חדשה יותר), הכוללת npm.
3. פתחו Terminal בתיקיית `chemistry-lab` והריצו:

```sh
npm install
npm run dev
```

4. פתחו את הכתובת ש-Vite מציג, בדרך כלל `http://127.0.0.1:5173`.
5. לעצירה: `Ctrl+C` בחלון ה-Terminal.

ההתקנה הראשונה דורשת אינטרנט להורדת החבילות. לאחר ההתקנה האתר אינו תלוי בשירות חיצוני, בפונטים מרוחקים, במפתח API או בתשלום. קישורי מקורות NIST נפתחים רק לפי בחירה. אין צורך לפתוח את `index.html` ישירות.

## מה כלול

כל עשר החבילות הועברו לנתונים מובנים ב-`src/courses.json`, בסדר הלימוד שנבחר:

P7 → P9 → P10 → P3 → P2 → P5 → P6 → P8 → P1 → P4.

- תיאוריה וסוגי תרגילים פתורים מכל החבילות.
- 57 שאלות מקוריות ומפתח תשובות מלא.
- שאלות בחירה, דירוג וחישוב עם בחירת יחידות נבדקות אוטומטית.
- שאלות פתוחות ארוכות: כותבים פתרון, חושפים את המפתח ומסמנים הערכה עצמית. האתר אומר זאת במפורש; אין בדיקת טקסט חכם ואין שירות AI.
- בחישוב מתקבלים כתיב רגיל וכתיב מדעי (`1.9e16`, `1.9×10^16`, וגם מעריכים עיליים). סבילות העיגול היא 1.5%, והיחידות חייבות להתאים ליחידה המבוקשת בשדה. אין המרת יחידות אוטומטית.
- לאחר מענה על כל שאלות הבוחן, הנושא מסומן כהושלם והאלקטרון שלו נדלק. גם תשובה שגויה נספרת כשאלה שנענתה, אבל אינה מעלה את הציון.
- תוצאות הבחנים וההשלמות נשמרות ב-localStorage. אפשר לאפס כל בוחן או את הכול דרך "על המעבדה".

## שמירה ופרטיות

הנתונים נשמרים רק בדפדפן ובכתובת שבהם משתמשים. אין סנכרון בין מכשירים, אין גיבוי בענן ואין אנליטיקה. ניקוי נתוני האתר, שימוש בדפדפן אחר או שינוי כתובת/פורט עשויים להציג התקדמות ריקה. טיוטת תשובה פתוחה זמנית אינה נשמרת לאחר מעבר שאלה. ה-ZIP נפתח עם התקדמות ריקה; התמונות של אטום מלא הן הדגמה מנתוני בדיקה בלבד.

## מפת האטום והספקטרום

מפת האטום היא המחשה אינטראקטיבית של התקדמות, לא תיאור פיזיקלי של מסלולי אלקטרונים. עשרת הסמנים הם נושאי הקורס. כל בוחן שהושלם מוסיף אלקטרון למונה; תצוגת הקונפיגורציה מתמלאת לפי `1s² 2s² 2p⁶`.

לכל נושא יסוד שונה וקווי פליטה מדודים של האטום הנייטרלי (`I`), מתוך NIST. אורכי הגל בקובץ הנתונים הם בננומטר; במקור הם באנגסטרם וחולקו ב-10. נבחרו קווים מייצגים בתחום 400-700 ננומטר, לא ספקטרום מלא. גובה ועוצמת הקווים עיצוביים. RGB הוא קירוב לצבע הנתפס של אורך גל; צבעי הטקסט הובהרו לצורך ניגודיות. בחירה נכונה מפעילה את זוהר קווי הפליטה ואנימציית פוטון, תוך כיבוד `prefers-reduced-motion`.

## תיקון ידוע בחומר המקור

ב-P10, סוג תרגיל 2, חבילת המקור כללה בטעות את Na ו-Mg ביסודות בעלי 5 פיקים ב-XPS. באתר תוקן: 5 תת-קליפות מאוכלסות מחייבות 3p מאוכלסת, ולכן Al-Ar (13-18 אלקטרונים). ל-Na ול-Mg ארבעה פיקים בלבד. מופיעה הערת תיקון גלויה בפתרון. קובצי DOCX המקוריים נכללו בקובץ ה-ZIP הפרטי שנמסר, ולא במאגר הקוד. מפתחות התשובות המקוריים והערכים המספריים שלהם נשמרו כפי שנמסרו. יתר החומר הועבר מחבילות הקורס, לא עבר בדיקה מדעית חדשה במסגרת בניית האתר.

## למפתחים

```sh
npm run build     # גרסת production בתיקיית dist
npm run preview   # תצוגה מקומית של build
npm test          # בדיקות נתונים, חישוב ושמירה
```

`src/main.jsx` - רכיבי הממשק; `src/style.css` - עיצוב ו-RTL; `src/logic.js` - לוגיקת בדיקה, צבע ושמירה; `src/courses.json` - כל חומר הלימוד. קובץ נעילה מצורף. אין תלות ב-Python בזמן התקנה או הפעלה.

הקוד נמצא במאגר GitHub שנוצר עבור הפרויקט. האתר מופץ דרך GitHub Pages מתוצרי build שנבנים מקומית ונשלחים לענף gh-pages, ללא GitHub Actions. אין רכיב שרת בפרויקט.

## מבנה רב־קורסי

הנתונים בנויים `courses -> topics -> content`. הקורס הקיים היחיד הוא כימיה אי־אורגנית, 84102. דף הבית הוא בורר קורסים, ומפת האטום נמצאת תחת `#course/84102`. כתובת נושא לדוגמה: `#course/84102/P7`. קישורי v1 כגון `#P7` עדיין עובדים.

להוספת קורס: מוסיפים רשומה למערך `courses` בקובץ `src/courses.json`, עם מזהה ייחודי, שם, תיאור, גוון accent ומערך topics. בכל נושא יש מטא־דאטה, spectrum (כולל accentWave), נתוני orbital אופציונליים ו-content המכיל theory/worked/quiz. אין צורך לשנות נתב או רכיבי מסך. אפשר למחזר מזהי נושא כמו P1 בקורס אחר: הבחירה, האטום וההתקדמות מופרדים לפי מזהה הקורס. אין כרטיסים לקורסים עתידיים ללא תוכן.

שמירה: `spectra-course-<course-id>-progress-v1` לכל קורס. התקדמות v1 קיימת מועתקת פעם אחת לכימיה אי־אורגנית, רק אם אין כבר נתונים עבור הקורס. המקור הישן אינו נמחק. איפוס מתוך קורס מאפס רק אותו, בלי למחוק קורסים אחרים. שינוי משמעותי במזהי קורס או שאלות מחייב תכנון הגירת נתונים.

## ברירת מחדל לכיווניות טקסט

כל טקסט JSX מוצג דרך `bidiElement`, הנקבע כ-JSX factory בקונפיגורציית Vite. `normalizeBidiText` מבודד רצפים לטיניים/מדעיים משמאל לימין וקבוצות סוגריים בעברית מימין לשמאל. זהו שלב תצוגה בלבד: נתוני הקורס, תשובות מספריות, ערכי יחידות, קישורים ומפתחות שמירה אינם משתנים. אין לשנות טקסט בצומת DOM לאחר ש-React רינדר אותו.

משוואות המכילות סימן שוויון/השוואה או חץ תגובה מוצגות כשורות נפרדות באופן אוטומטי. מספרים ויחידות קצרים נשארים בתוך המשפט. קבוצת סוגריים מעורבת המכילה נוסחה מוצגת כיחידה מבודדת בשורה משלה, כדי לא לפצל את הסוגריים. נוסחאות ארוכות יכולות להישבר או לגלול בתוך רוחב הרכיב. להוספת טקסט חדש אין צורך לסמן מחרוזות ידנית. רכיבי React שיתווספו בעתיד צריכים לייבא את `bidiElement` כל עוד משתמשים ב-JSX factory זה.
