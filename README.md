# SPECTRA - המעבדה האישית לכימיה

אתר לימוד אישי בעברית, React + Vite, ללא שרת וללא חשבון.

## הפעלה במק

1. חלצו את קובץ ה-ZIP.
2. נדרשת התקנת Node.js בגרסת 20.19 ומעלה (או גרסת LTS חדשה יותר), הכוללת npm.
3. פתחו Terminal בתיקיית `chemistry-lab` והריצו:

```sh
npm install
npm run dev
```

4. פתחו את הכתובת ש-Vite מציג, בדרך כלל `http://127.0.0.1:5173`.
5. לעצירה: `Ctrl+C` בחלון ה-Terminal.

ההתקנה הראשונה דורשת אינטרנט להורדת החבילות. לאחר ההתקנה האתר אינו תלוי בשירות חיצוני, בפונטים מרוחקים, במפתח API או בתשלום. קישורי מקורות NIST נפתחים רק לפי בחירה. אין צורך לפתוח את `index.html` ישירות.

## מה כלול

כל עשר החבילות הועברו לנתונים מובנים ב-`src/content/courses.json`, בסדר הלימוד שנבחר:

P7 → P9 → P10 → P3 → P2 → P5 → P6 → P8 → P1 → P4.

- תיאוריה וסוגי תרגילים פתורים מכל החבילות.
- 57 שאלות מקוריות ומפתח תשובות מלא.
- שאלות בחירה, דירוג וחישוב עם בחירת יחידות נבדקות אוטומטית.
- שאלות פתוחות ארוכות: כותבים פתרון, חושפים את המפתח ומסמנים הערכה עצמית. האתר אומר זאת במפורש; אין בדיקת טקסט חכם ואין שירות AI.
- בחישוב מתקבלים כתיב רגיל וכתיב מדעי (`1.9e16`, `1.9×10^16`, וגם מעריכים עיליים). סבילות העיגול היא 1.5%, והיחידות חייבות להתאים ליחידה המבוקשת בשדה. אין המרת יחידות אוטומטית.
- לאחר מענה על כל שאלות הבוחן, הנושא מסומן כהושלם והאלקטרון שלו נדלק. גם תשובה שגויה נספרת כשאלה שנענתה, אבל אינה מעלה את הציון.
- תוצאות הבחנים וההשלמות נשמרות ב-localStorage. אפשר לאפס כל בוחן או את הכול דרך "על המעבדה".

## שמירה ופרטיות

הנתונים נשמרים רק בדפדפן ובכתובת שבהם משתמשים. אין סנכרון בין מכשירים, אין גיבוי בענן ואין אנליטיקה. ניקוי נתוני האתר, שימוש בדפדפן אחר או שינוי כתובת/פורט עשויים להציג התקדמות ריקה. טיוטת תשובה פתוחה זמנית אינה נשמרת לאחר מעבר שאלה. ה-ZIP נפתח עם התקדמות ריקה; התמונות של אטום מלא הן הדגמה מנתוני בדיקה בלבד.

## מפת האטום והספקטרום

מפת האטום היא המחשה אינטראקטיבית של התקדמות, לא תיאור פיזיקלי של מסלולי אלקטרונים. עשרת הסמנים הם נושאי הקורס. כל בוחן שהושלם מוסיף אלקטרון למונה; תצוגת הקונפיגורציה מתמלאת לפי `1s² 2s² 2p⁶`.

לכל נושא יסוד שונה וקווי פליטה מדודים של האטום הנייטרלי (`I`), מתוך NIST. אורכי הגל בקובץ הנתונים הם בננומטר; במקור הם באנגסטרם וחולקו ב-10. נבחרו קווים מייצגים בתחום 400-700 ננומטר, לא ספקטרום מלא. גובה ועוצמת הקווים עיצוביים. RGB הוא קירוב לצבע הנתפס של אורך גל; צבעי הטקסט הובהרו לצורך ניגודיות. בחירה נכונה מפעילה את זוהר קווי הפליטה ואנימציית פוטון, תוך כיבוד `prefers-reduced-motion`.

## תיקון ידוע בחומר המקור

ב-P10, סוג תרגיל 2, חבילת המקור כללה בטעות את Na ו-Mg ביסודות בעלי 5 פיקים ב-XPS. באתר תוקן: 5 תת-קליפות מאוכלסות מחייבות 3p מאוכלסת, ולכן Al-Ar (13-18 אלקטרונים). ל-Na ול-Mg ארבעה פיקים בלבד. מופיעה הערת תיקון גלויה בפתרון. קובצי DOCX המקוריים נכללו בקובץ ה-ZIP הפרטי שנמסר, ולא במאגר הקוד. מפתחות התשובות המקוריים והערכים המספריים שלהם נשמרו כפי שנמסרו. יתר החומר הועבר מחבילות הקורס, לא עבר בדיקה מדעית חדשה במסגרת בניית האתר.

ב-P7, סוג תרגיל 4, תשובת V⁺ היא [Ar]4s¹3d³ לפי כלל ההוצאה הנלמד בקורס, עם הבחנה גלויה ממצב היסוד של היון החופשי בגז, [Ar]3d⁴ לפי NIST. נתוני NIST בטבלה המחזורית נשארו ללא שינוי. ראו [תיעוד המקורות והבדיקות](docs/vanadium-course-answer.md).

## למפתחים

```sh
npm run build     # גרסת production בתיקיית dist
npm run preview   # תצוגה מקומית של build
npm test          # בדיקות נתונים, חישוב ושמירה
```

`src/main.jsx` - רכיבי הממשק; `src/style.css` - עיצוב ו-RTL; `src/logic.js` - לוגיקת בדיקה, צבע ושמירה; `src/content/courses.json` - כל חומר הלימוד. קובץ נעילה מצורף. אין תלות ב-Python בזמן התקנה או הפעלה.

הקוד נמצא במאגר GitHub שנוצר עבור הפרויקט. האתר מופץ דרך GitHub Pages מתוצרי build שנבנים מקומית ונשלחים לענף gh-pages, ללא GitHub Actions. אין רכיב שרת בפרויקט.

## מבנה רב־קורסי

הנתונים בנויים `courses -> topics -> content`. הקורס הראשון וברירת המחדל הוא כימיה אי־אורגנית, 84102. נוסף אליו כימיה כללית א׳, 84101, עם תוכן נפרד. דף הבית הוא בורר קורסים, ומפת האטום נמצאת תחת `#course/84102`. כתובת נושא לדוגמה: `#course/84102/P7`. קישורי v1 כגון `#P7` עדיין עובדים.

Course and topic order is now explicit in the split catalogues. Add course metadata to `src/content/courses.json`, topic references to `src/content/<course-id>/topics.json`, and complete topic objects to `src/content/<course-id>/topics/<topic-id>.json`. The shared loader preserves the existing catalogue shape, routes and progress IDs. See [course content layout](docs/course-content-layout.md) for the contract, editing scripts and checks.

שמירה: `spectra-course-<course-id>-progress-v1` לכל קורס. התקדמות v1 קיימת מועתקת פעם אחת לכימיה אי־אורגנית, רק אם אין כבר נתונים עבור הקורס. המקור הישן אינו נמחק. איפוס מתוך קורס מאפס רק אותו, בלי למחוק קורסים אחרים. שינוי משמעותי במזהי קורס או שאלות מחייב תכנון הגירת נתונים.


## כימיה כללית א׳ - 84101

מהדורת לימוד נגזרת ראשונה: 12 נושאים, 24 דוגמאות פתורות ו-60 שאלות בחירה, חישוב, דירוג והערכה עצמית. המקור הוא ארכיון ההרצאות והתרגולים שנמסר, ובו 16 קבצים (כולל גרסאות DOCX/PDF של אותו תרגיל). זו אינה העתקה מלאה של כל שאלה בארכיון ואינה מפתח רשמי. הסיכומים והפתרונות נערכו וחושבו עבור האתר. המקורות מצוינים לפי קובץ ועמוד או שאלה בכל נושא ובדוגמאות. אין במאגר קובצי הרצאה, חומר גולמי או פרטי קשר מהמסמכים.

מספר הקורס מבוסס על `lecture 8 Mastai.pdf` עמ׳ 1, שם מופיע 84-101-01.

סדר הנושאים: חומר ויחידות; אטומים ומולים; הרכב ונוסחאות; סטויכומטריה; מגיב מגביל וניצולת; תמיסות; תגובות מימיות; חמצון־חיזור; גזים אידיאליים; תורה קינטית וגזים ממשיים; כוחות בין־מולקולריים; פאזות ומוצקים.

תיקונים מפורשים בחומר הנגזר:
- GC1 עמ׳ 14: ערך אטמוספרה נלקח מדף הנוסחאות של הבוחן, כ-101.33 kPa, ולא מערך הדפוס השגוי בשקופית.
- תרגיל 2 שאלה 2: מסות האיזוטופים המדויקות נותנות שכיחות 69.15% ל-X-63. הפתרון הממולא מעגל מוקדם ומציג 67.5%.
- GC5 עמ׳ 52: התא בעל 4 אטומים ונצילות 0.74 הוא FCC, אף שכותרת השקופית אומרת BCC.
- מהירות RMS מובחנת ממהירות ממוצעת; אנרגיה למול מבודלת מאנרגיה למולקולה. בכמה נוסחאות בדף המסכם מופיעים תיוגים לא מדויקים.

הבחנים נבדקו בפורמט ובחישובים המספריים. שאלות פתוחות מסומנות כהערכה עצמית. הקורס אינו מחליף בדיקה מול המרצה או חומר הקורס העדכני. לוח הצבעים משתמש בקווי NIST שכבר תועדו בפרויקט; בחלק מהנושאים חוזרים ליסוד קודם. אין תמונת אורביטל מלאכותית בנושא שאינו דן באורביטלים.
## ברירת מחדל לכיווניות טקסט

כל טקסט JSX מוצג דרך `bidiElement`, הנקבע כ-JSX factory בקונפיגורציית Vite. `normalizeBidiText` מבודד רצפים לטיניים/מדעיים משמאל לימין וקבוצות סוגריים בעברית מימין לשמאל. זהו שלב תצוגה בלבד: נתוני הקורס, תשובות מספריות, ערכי יחידות, קישורים ומפתחות שמירה אינם משתנים. אין לשנות טקסט בצומת DOM לאחר ש-React רינדר אותו.

כיווניות אינה קובעת פריסה: ברירת המחדל היא טקסט בתוך המשפט, גם כשמופיע סימן שוויון או חץ. רצפים קצרים (עד 18 תווים, ללא רווח או עם סימן השוואה) נשארים יחד כדי לא להפריד סימן ממספר. ערכים ארוכים אינם מקבלים איסור שבירה גורף. טקסט SVG נשאר טקסט SVG, ולא מקבל תגיות HTML.

בחירה מפורשת של פריסה בנתוני פסקת תיאוריה:
- `layout: "equation"`: נוסחה עצמאית בתוך `DisplayMath`, בכיווניות LTR ובגלילה מקומית אם היא רחבה. שלושה רווחים או יותר בין נוסחאות במקור מפרידים שורות תצוגה, ללא שינוי במחרוזת המקור.
- `definition`: פתיח (`intro`), תחום (`range`) ורשימת זוגות מונח/ערך (`mappings`). מוצג באמצעות `Definition` כרשימה סמנטית רספונסיבית, ולא כנושא לימוד חדש.
- `ScientificText` מקבל `runs`: מחרוזות רגילות, `{math: "l = 0"}` לבידוד מפורש, או `{keep: [...]}` ליחידה קצרה שצריכה להישאר יחד. אין להקיף פסקה או נוסחה ארוכה ב-`keep`.

משאירים את `text` המקורי ללא שינוי ומשתמשים בנתוני התצוגה הנוספים רק כשצריך שליטה סמנטית. אין לנסות לזהות פריסת משוואה לפי סימני פיסוק. רכיבי JSX חדשים מייבאים `bidiElement`; רכיב מדעי שנכתב באמצעות React.createElement אחראי לבידוד המפורש שלו. אין לגעת בתשובות, יחידות מכונה או מפתחות אחסון לצורך תיקון תצוגה.

## תפריט הליום ואיפוס

כפתור האטום בסרגל העליון פותח תפריט אישי ללא התחברות, עם התקדמות כוללת בכל הקורסים. האווטאר הוא SVG מוטמע ושני אלקטרונים באנימציית CSS. זו המחשה קלאסית דקורטיבית, לא מודל קוונטי או מסלול פיזיקלי. מצב reduced motion עוצר את האנימציה. אין תמונות, ספריות או בקשות רשת חדשות.

"איפוס כל ההתקדמות" מחייב שלב אישור נוסף, עם מיקוד ברירת מחדל בביטול. האיפוס מוחק את מפתחות ההתקדמות של SPECTRA בלבד בכל הקורסים, כולל מפתח v1 הישן כדי שלא תתחדש התקדמות בהגירה. הוא לא מוחק חומר לימוד או נתונים של אתרים אחרים באותו origin. Escape או לחיצה מחוץ לתפריט סוגרים בלי לאפס. אם האחסון חסום מוצגת שגיאה והמסך אינו מסומן כמאופס. איפוס הבוחן/הקורס הקיים נשאר נפרד.
